# hanselius.dev

Hansel's personal website: life as an orchestra. The landing page is a 3D concert
hall where every section of the orchestra is a section of the site — the conductor
on the podium is *About me*, the choir risers are *Choir*, the violins are *Music*,
the cellos and basses are *Swim*, the woodwinds are *Cooking*, the brass is *Work*,
the timpani are *Coding*, and the audience is *Social*. Pressing **Begin the
overture** plays a synthesized, endlessly looping arrangement of the Ode to Joy
theme from Beethoven's 9th, with each section of the orchestra (and the page)
joining in the order Beethoven wrote: cellos first, then violins, winds, brass,
timpani, and finally the choir.

## Running it locally

No build step, no install. Either double-click `index.html`, or (slightly better,
because it matches how a web server behaves):

```sh
cd "/Users/hansel/Hansel Website"
python3 -m http.server 8000
# then open http://localhost:8000
```

## How it's put together (and why)

Everything is **one `index.html` file** on purpose:

- **No frameworks, no build tools.** A personal site this size doesn't need React
  or a bundler; a single file means nothing can break between "edit" and "reload",
  which is the best property a site can have while you're learning.
- **All graphics are generated by code.** The orchestra is built from Three.js
  primitives (6-sided cones for bodies, low-poly icosahedrons for heads, boxes and
  cylinders for instruments) created in JavaScript at page load. There are no
  image or model files to design, store, or pay for, and the figures stay sharp at
  any resolution.
- **All sound is synthesized live** with the browser's built-in Web Audio API.
  Beethoven's score is public domain, but *recordings* of it are not — so the page
  plays the notes itself (detuned sawtooths for strings, filtered "formants" for
  the choir's *aah*, a pitch-dropping sine for timpani). Zero audio files, zero
  copyright risk, zero hosting cost.
- **The only external dependency is Three.js**, loaded from the cdnjs CDN, pinned
  to an exact version (r128) so the site can never break because a library
  updated underneath it. Fonts come from Google Fonts.

### Map of index.html

| Part | What it does |
|---|---|
| `<style>` block | All CSS. Colors are defined once as variables (`--bg`, `--accent`, …) at the top so retheming is a 6-line change. |
| The veil `<div>` | The blurred "Begin the overture" screen. Browsers refuse to play audio until the user interacts, so this button is required, not just decorative. |
| `<main>` | The page content: hero, the 3D stage container, the "programme" (section cards that are the real navigation targets), social links, footer. |
| Audio engine (JS) | Synth voices (strings/brass/winds/timpani/choir/applause) and the sequenced Ode to Joy data (`PHR_A`, `PHR_B`, bass lines). `scheduleCycle()` books one full build-up on the audio clock; `queueCycle()` books the next one just before the current one ends, which is what makes the loop seamless. |
| 3D stage (JS) | Builds the orchestra, places players on arcs around the podium, animates them procedurally (sine waves with a random phase per player), and handles hover/click via raycasting. |

## Deployment plan (all free until the domain)

1. Develop locally in this repo; commit as we go.
2. When ready to go live: enable **GitHub Pages** on this repo
   (Settings → Pages → deploy from `main` branch). The repo must be public for
   free Pages. The site then lives at `https://hanspres1999.github.io/hanselius.dev/`.
3. Later, buy the domain (~US$10–15/year, the only money involved) and point it
   at Pages in the same settings screen.
